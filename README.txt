PORTOFOLIO SYALY — TEMPLATE HTML/CSS/JS

Cara menjalankan:
1. Ekstrak folder ini.
2. Buka index.html di browser, atau buka folder menggunakan Visual Studio Code.
3. Edit konten di index.html.
4. Edit warna, ukuran, dan layout di style.css.
5. Edit interaksi menu/filter proyek di script.js.

Bagian yang perlu diganti:
- Foto: ganti elemen .photo-placeholder dengan tag <img src="assets/foto-kamu.jpg" alt="Foto Syaly"> dan simpan foto di folder assets.
- Email: ganti emailkamu@example.com.
- LinkedIn/GitHub: ganti URL profil pada index.html.
- Proyek: ganti judul, deskripsi, dan kategori dengan proyek asli; tambahkan gambar jika ada.

Catatan: Ini adalah implementasi baru yang terinspirasi dari gaya portofolio gelap dan fitur umum template Unfold, bukan salinan verbatim kode sumber ThemeWagon. Untuk kode asli, gunakan halaman resmi ThemeWagon dan periksa lisensinya.
